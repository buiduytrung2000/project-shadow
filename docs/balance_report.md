## Methodology

**Hero metrics** (group = `Role`):
- **DPS** = mean(`Damage Multiplier` of all offensive Available Skills) × `Base Accuracy` / 100
- **Survivability** = `Base HP` (raw; positional defense not folded in)
- **Stress Output** = mean(`Stress Damage` of offensive Available Skills)
- **Speed** = raw `Speed` (turn-order advantage)
- Skill scope: **all 10 Available Skills** per hero (full kit), filtered to `Is Offensive = Yes`

**Enemy metrics** (group = `Variant Type`):
- **Threat** = `Base HP` × (`Damage Min` + `Damage Max`) / 2 / 100
- **Accuracy** = raw `Accuracy`

**Outlier detection:** per-group mean μ, sample SD σ. Flag when `|x − μ| > 1.5σ`. Severity **HIGH** if `> 2σ`, **MEDIUM** if `1.5–2σ`. Small groups (n < 3) produce noisy SD — flags still reported but treat with caution.

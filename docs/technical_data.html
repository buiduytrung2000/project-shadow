3. API nội bộ (pseudocode)

Combat Manager

// Khởi tạo combat với đội hình hero và enemy list
void StartCombat(List<Hero> heroes, List<Enemy> enemies);

// Xác định thứ tự lượt dựa trên speed (Combatant.speed + random)
List<Combatant> DetermineTurnOrder();

// Xử lý một lượt của combatant (hero hoặc enemy)
void ProcessTurn(Combatant current);

// Khi hero chọn skill
void UseSkill(Hero user, Skill skill, List<Combatant> targets);

// Tính toán sát thương (xem game_systems.html § 6)
int CalculateDamage(Hero attacker, Enemy target, Skill skill, bool isCrit);

// Áp dụng effect (stun, poison, riposte, heal, stress...)
void ApplyEffect(Combatant target, Effect effect);

// Kiểm tra kết thúc combat (mọi hero hoặc mọi enemy có HP <= 0)
bool IsCombatEnded();

4. Flowcharts

Combat Turn Flow

Start Turn │ ▼ Determine Turn Order (by speed) │ ▼ ┌─→ Has combatant left? ──No──→ End Combat │ │ Yes │ ▼ │ Combatant type? │ ├─ Hero → Show skill menu → Player chooses → Calculate dmg & effects ─┐ │ │ │ │ └─ Enemy → AI picks skill → Use on target ───────────────────────────┤ │ │ └──────────────── Apply damage, stress, effects ◄──────────────────────────┘ │ ▼ Remove dead combatants │ └───── loop ─────►

Stress Resolution Flow

Add Stress │ ▼ Stress >= 100? ──No──→ Return │ Yes ▼ Resolve → random(0,1) │ ├── ≤ 0.7 → Pick random Affliction → Apply modifiers ──┐ │ │ └── > 0.7 → Pick random Virtue → Apply buffs ────┤ │ Set stress to 0 ◄─────────────┘

Dungeon Pathway Flow

Enter Dungeon → Load stage_N.json │ ▼ ┌─→ Current node index < total? ──No──→ Fight boss → End stage │ │ Yes │ ▼ │ Get current node │ │ │ ▼ │ Node type? │ ├─ Combat → Start combat → Win? → rewards + advance │ ├─ Event → Trigger event → outcomes → advance │ ├─ Rest → Choose hero → stress reduce → advance │ ├─ Reward → Roll drop table → give items → advance │ └─ Choice → Show 2-3 branches → player picks → next layer │ │ └──────────────────────────────────────────────────────────►─┘

Event Processing Flow

Trigger Event → Load event data │ ▼ Show description + choices │ ▼ Player selects choice │ ▼ For each outcome in choice: │ ▼ random check → Pass → Apply outcome effect → Fail → Skip │ ▼ Update UI + game state │ ▼ Continue dungeon

Hamlet Management Flow

Enter Hamlet → Show main UI │ ▼ Player action? ├─ Upgrade building → Check gold + level → Upgrade ├─ Cure disease → Select hero + disease → Pay gold → Remove ├─ Reduce stress → Select hero → Pay gold → -stress ├─ Recruit hero → Generate random hero → Add to roster └─ Start next stage → Load dungeon

11.4 SaveMigration utility (Sprint 9+ B3 + Sprint 10 B1)

  • CURRENT_RUN_VERSION = 1
  • CURRENT_META_VERSION = 2 (Sprint 10 B1)
  • loadMeta(): parses JSON tree, bumps saveVersion field to current if older. Compact constructor back-fills new fields (heirloom=0, buildingLevels=all-Lv1, cureSlots=0) for legacy v1 saves.
  • IncompatibleSaveException: thrown when JSON saveVersion > current build — prevents silent data loss on downgrade.
  • Atomic write: .tmp sibling + Files.move(ATOMIC_MOVE, REPLACE_EXISTING). Falls back to REPLACE_EXISTING on filesystems without atomic move.

11.5 Path traversal guard

SaveManager.filePathFor(runId) asserts runId matches regex [A-Za-z0-9_-]+. Rejects .., /, \, ./, blank. Future-proofs against user-input runId pathways.

12. ConditionResolver runtime (Sprint 11 B2 + Sprint 12 B1)

Data-driven trait/disease effect dispatcher. Reads Trigger column from diseases_traits.csv to route handlers. 9 conditions runtime-implemented (3 traits Sprint 11 B2 + 4 traits + 5 diseases Sprint 12 B1 + Cursed Sprint 11 B3).

// Hook points
ConditionResolver.onCombatStart(encounter)
    → reset Bloodthirsty stacks, Cowardly flag
ConditionResolver.onTurnStart(hero, encounter, rng)
    → Cowardly trigger if stress > 50 (20% skip)
    → Paranoid aura (+1 stress all allies)
    → Nightmare (+2 stress self)
ConditionResolver.onSelfDamage(self, encounter)
    → Masochist propagates +5 stress to allies
ConditionResolver.onKill(killer)
    → Bloodthirsty stack +1 (cap 5)

// Stat aggregators (called in DamageFormula / Hero override)
outgoingDamageMultiplier(hero)   → Fearful × 0.80
accuracyDebuff(hero)             → Hopeless -10 + Blindness -20
maxHpMultiplier(hero)            → Fever × 0.85, Plague × 0.75 (multiplicative)
rollParanoiaActionFail(hero, rng) → 15% chance fail
hasForcedAttack(hero)            → Bloodthirsty true

Sprint 3 stress event hooks (Sprint 12 B1 finally landed)

STRESS_ON_CRIT = 5            // Enemy crits Hero target → +5 stress

13. XP system (Sprint 12 B2)

// Hero.currentXp accumulator + xpRequiredForNextLevel
xpRequiredForNextLevel = { 100, 200, 350, 500, 750 }  // Lv 0→1→2→3→4→5

// Per-kill XP grant (CombatController.resolveAction)
killerXp = KILL_XP_BASE × variantMultiplier
  where variantMultiplier:
    Boss → 5.0
    Miniboss → 2.5
    Tank / Special / Assassin → 1.2
    Base → 1.0
allyXp = killerXp × 0.5  // surviving non-killer allies

// End-of-stage bonus (ProjectShadowGame.handleCombatWin BossNode branch)
+50 XP per alive hero on boss kill

// Guild level-up (HamletService.levelUpHero)
requires BOTH gold (existing) AND xp (new) — throws error.notEnoughXp if xp insufficient

14. Event outcome DSL (Sprint 10 B3)

CSV events.csv Choice N Outcomes column uses pipe-separated key=value within semicolon-separated effect list.

// Format: "type=X|target=Y|value=Z|chance=0.5; type=...; ..."
// Example from event_open_tomb:
"type=gold|value=300|chance=0.5; type=damage|target=random_hero|value=8-15|chance=0.3; type=stress|target=party|value=10|chance=0.2"

// Supported types (EventOutcomeApplier):
//   gold              (value: int or "min-max")
//   stress            (target: party | random_hero, value: int or range)
//   damage            (target: party | random_hero, value: int or range)
//   skill_cd_reset    (target: random_hero, value: "all")
//   trait_apply       (target: random_hero, value: trait_id)
//   disease           (target: random_hero, value: disease_id)
//   item              (value: item_id)
//   none              (no-op, used as fallback in chance distributions)

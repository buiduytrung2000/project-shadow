🌳 Stage 1 — Pathway dạng cây ngẫu nhiên

JSON layered_tree, pools, rules, thuật toán sinh stage

1. Tổng quan thiết kế

Mô hình: layered_tree 3 lớp + boss cuối.

Topology: fully_connected giữa các lớp — mỗi node ở lớp N kết với mọi node ở lớp N+1.

Total nodes: 6 (1 fixed start + 2 layer-2 + 2 layer-3 + 1 boss).

Paths per run: 4 đường khả thi xuống boss.

Sơ đồ trực quan

[L1.A — Combat fixed (1 goblin)] │ ┌────────┴────────┐ ▼ ▼ [L2.1 random] [L2.2 random] │ │ ┌───────┼───────┐ ┌───────┼───────┐ ▼ ▼ ▼ ▼ ▼ ▼ (fully connected) [L3.1 random] [L3.2 random] │ │ └────────┬────────┘ ▼ [BOSS] enemy_b01 Giant Zombie

3. Pools chi tiết

3.1 Combat pool

  • default — dùng cho layer 2/3 nếu không phải pre-boss. Pool: enemy_01, enemy_02. Variants: Base/Tank/Assassin. 2–3 enemies/trận.
  • pre_boss — kích hoạt nếu node L3 là combat & path đi thẳng tới boss. Pool nhỏ: 1× enemy_01 Base. Mục đích: "đệm nhẹ trước boss".

3.3 Rest pool

  • Nghỉ ngơi — single hero, -10..-20 stress
  • Cảnh giới — single hero, +8..+15 HP
  • Trò chuyện — party, -5..-8 stress

4. Rules — ràng buộc khi sinh stage

RuleMục đích
no_consecutive_restTránh 2 node rest liên tiếp gây trivial
no_consecutive_rewardTránh 2 reward liền — không cho cướp loot
max_combat_per_run: 3Tối đa 3 trận trong stage (kể cả boss)
min_event_per_run: 1Bắt buộc có ít nhất 1 event trên đường — đảm bảo flavor
L3 + pre-boss path → pre_boss poolNếu L3 là combat & node tiếp theo là boss → buộc dùng pre_boss pool (1 goblin)
full_party_HP → reward replaceNếu vào L3 với toàn đội full HP → thay 1 node L3 bằng reward (bonus)

5. Thuật toán sinh stage (pseudocode)

function generate(stage_config, seed) {
    rng = Random(seed)
    tree = {}

    // Layer 1: fixed
    tree.L1 = stage_config.first_node_fixed

    // Layer 2: 2 nodes random từ weighted pool
    for i in 0..stage_config.layer_2.num_nodes:
        node_type = weighted_pick(rng, stage_config.layer_2.weights)
        tree.L2[i] = generate_node(node_type, stage_config.pools)

    // Layer 3: 2 nodes random + bias-away-from-combat nếu came_from_combat
    for i in 0..stage_config.layer_3.num_nodes:
        weights = clone(stage_config.layer_3.weights)
        if any_path_from_L2_to_L3[i] came_from "combat":
            weights["combat"] = weights["combat"] / 2     // bias away
        node_type = weighted_pick(rng, weights)
        tree.L3[i] = generate_node(node_type, stage_config.pools)

    // Boss: fixed
    tree.BOSS = stage_config.last_node_fixed

    // Apply rules / constraints
    enforce(tree, stage_config.rules)
    return tree
}

function enforce(tree, rules) {
    for rule in rules:
        switch rule:
            case "no_consecutive_rest":
                // Nếu L2[i] = rest và L3[j] connected = rest → re-roll L3[j]
            case "max_combat_per_run":
                // Nếu đường nào có > 3 combat → re-roll 1 node combat thành event
            case "min_event_per_run":
                // Nếu đường nào không có event → buộc L2 hoặc L3 thành event
            case "if_player_has_full_party_hp_before_boss":
                // Track ở runtime: nếu vào L3 mà party full HP → 1 L3 → reward
}

function generate_node(type, pools) {
    switch type:
        case "combat":
            pool = pools.combat.default
            num_enemies = rng.range(pool.min_enemies, pool.max_enemies)
            enemies = [pick_with_variant(pool.enemies, pool.variants_allowed)
                       for _ in 0..num_enemies]
            return CombatNode(enemies)
        case "event":
            event_id = weighted_pick(rng, pools.event.weights)
            return EventNode(event_id)
        case "rest":
            return RestNode(options = pools.rest.options)
        case "reward":
            drops = [weighted_pick(rng, pools.reward.drop_table)
                     for _ in 0..pools.reward.rolls]
            return RewardNode(drops)
}

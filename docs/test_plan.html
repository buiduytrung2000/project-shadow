🧪 Test Plan chi tiết

Checklist test thủ công cho từng Sprint đã hoàn thiện · 9 Sprints + extras

Cách dùng: Mỗi section là 1 Sprint. Trong section là checklist các case cần verify thủ công (cộng thêm 247 unit test tự động đã pass). Đánh dấu ☐ → ✅ sau khi test PASS. Nếu FAIL → tạo bug ticket + ghi vào "Known issues" cuối doc.

Save data: ./gradlew lwjgl3:run → save vào assets/saves/. IDE chạy từ root → save vào saves/.

Sprint 2 — Domain Models + Combat Logic

Deliverable: Hero/Combatant/CombatEncounter classes. Turn order theo speed. Damage formula đầy đủ.

Auto tests

  • DamageFormulaTest — verify công thức: base × skill_mult + flat × crit × armor × random_range
  • CombatantStateTest — HP, stress, position, alive state
  • CombatEncounterTest — turn order generation
  • TargetSelectorTest — front/back/single/random/aoe targeting
  • CombatControllerTest — high-level turn loop
  • HealSkillTest — heal skills target ally đúng + magnitude đúng

Manual checklist (in-game)

  • Embark party 4 hero → enter combat node L1.A (Goblin) → expect grid 4 vs 1
  • Check turn order panel: hero với speed cao nhất đi trước (Sát Thủ speed=8 trước Chiến Binh speed=3)
  • Click skill button → target picker hiển thị → pick enemy → damage được tính theo formula
  • Trigger crit (lặp combat nhiều lần) → khi crit, hiển thị visual highlight + damage gấp 1.5×
  • Hero HP về 0 → hero state = dead, không thể chọn skill
  • Hero stress lên 100 → check Affliction/Virtue resolution trigger (70/30 chance)
  • Enemy HP về 0 → removed khỏi combat grid
  • Tất cả enemies dead → win callback → trở về StageMapScreen
  • Tất cả heroes dead → lose callback → GameOverScreen

Sprint 3 — Effect Resolver

Deliverable: 134 effects implementable via data-driven dispatcher.

Auto tests

  • EffectInstanceTest — apply/tick/dispel lifecycle
  • ActiveEffectsTest — stacking (max stacks, refresh duration)
  • CombatScenarioTest — full combat with effects applied

Manual checklist

  • Hero dùng skill có effect eff_poison → enemy: -X HP/lượt × 3 lượt → verify HP giảm đều mỗi turn
  • Áp 3 stack poison cùng 1 enemy → check max_stacks=3 (không chồng quá)
  • Hero dùng eff_stun → enemy skip lượt tiếp theo (verify trong turn order)
  • Hero dùng eff_dmg_buff trên đồng đội → 2 lượt sau attack → damage tăng đúng %
  • Hero bị eff_burn 5 stacks → 5 lượt sau → mỗi lượt -2×5=10 HP
  • Hero có eff_dodge 20% → mò khoảng 5 đòn → ~1 đòn miss (visual indicator)
  • Effect duration giảm sau mỗi lượt → khi reach 0 → effect dispel + visual marker biến mất
  • Permanent effect (eff_perm_dmg) → không tự dispel sau combat

Sprint 4 — Stage Generator

Deliverable: Sinh ngẫu nhiên StageTree từ stage_*.json với rules + pools.

Auto tests

  • StageGeneratorIntegrationTest — generate stage_1 với seed cố định → tree đúng spec
  • StageRulesTest — no_consecutive_rest/reward, max_combat, min_event
  • StageTreeTest — graph topology, edges, reachability

Manual checklist

  • Generate stage_1 với 5 seed khác nhau → verify mỗi seed cho tree khác → đảm bảo randomness
  • Mỗi tree đều có đúng 6 nodes (L1.A fixed + 2 L2 + 2 L3 + BOSS)
  • Edges đầy đủ: L1.A nối tới cả L2.1 và L2.2; mỗi L2 nối tới cả L3.1 và L3.2; L3 nối tới BOSS
  • Count combat nodes per path ≤ 3 (rule)
  • Mỗi path có ≥ 1 event node (rule)
  • L1.A luôn là combat với 1 enemy_01 Goblin (tutorial)
  • BOSS luôn là enemy_b01 Giant Zombie
  • Edge case: nếu L3 đường tới boss = combat → enemy pool = pre_boss (1 goblin only)
  • Edge case: party HP full → spawn extra reward node thay 1 L3 node

Sprint 5 — Rendering & UI

Deliverable: Combat scene 4v4 với sprite, HP bar, stress bar, skill row.

Auto tests

  • SpriteAnimatorTest — frame timing, looping, completion callback
  • SpriteAtlasTest (implicit) — atlas region lookup
  • ParticleSystemTest — particle spawn, decay, color
  • CombatantViewTest (implicit thru CombatRenderer)

Manual checklist (in-game visual)

  • Start combat → 4 hero sprites bên trái (east-facing), 1-3 enemy sprites bên phải (west-facing)
  • Mỗi sprite hiển thị đúng character (Chiến Binh có giáp đỏ, Pháp Sư có robe xanh, ...)
  • HP bar phía trên mỗi sprite hiển thị HP/maxHP đúng tỷ lệ + màu (xanh / vàng / đỏ theo %)
  • Stress bar phía dưới mỗi hero hiển thị stress (0-100, màu trắng → đỏ)
  • Idle animation tự loop liên tục (sprite breath/sway)
  • Hero turn → 4 skill button row hiển thị + tên skill VN đúng
  • Click skill → highlight, target picker (chỉ enemy hợp lệ)
  • Click target → attack animation play 1 lần → impact frame
  • Damage number popup (-X) bay lên từ target sprite
  • Enemy turn → enemy sprite play attack animation
  • Hero bị đòn → hurt animation 1 lần → quay lại idle
  • Hero/enemy chết → dead animation play 1 lần → sprite stay ở frame cuối
  • Stress lên 100 → resolve animation (Affliction/Virtue visual)
  • Sprite atlas load không lỗi (console không có "missing region" warning)

Sprint 6 — Save System

Deliverable: Save/load run state JSON với permadeath archive.

Auto tests

  • SaveManagerTest — save/load/list/archive lifecycle
  • RunStateTest — serialization, version field
  • HeroStateTest — snapshot/restore Hero ↔ HeroState

Manual checklist

  • Bắt đầu fresh: xóa saves/ folder → launch game → expect tự tạo saves/meta.json với FRESH_GOLD=200 + 2 default heroes
  • Embark stage 1 → check saves/run_<timestamp>.json được tạo (active run)
  • Hoàn thành 1 combat → run.json update (currentNode changed, gold updated)
  • Đóng game giữa run → reopen → "Continue Run" button enabled trên HamletScreen

  • Hoàn thành stage (kill boss) → run.json move sang saves/archive/run_<ts>.json
  • Game Over (party wipe) → run.json archive luôn + meta lưu gold=0 (forfeit) + dead heroes removed
  • Mở meta.json → check format: { "gold": ..., "roster": [...], "trinketInventory": [...], "createdAt": ..., "lastSavedAt": ... }
  • Mở 1 archive run.json → check chứa full state lúc kết thúc
  • Edit meta.json manually → set gold = 999999 → relaunch → expect game đọc đúng (no crash, gold = 999999)
  • Corrupt meta.json (invalid JSON) → relaunch → expect graceful error, NOT crash silent

  • Same stage seed → cùng boss drop (deterministic)
  • Verify auto: BossRewardParsingTest 5 cases pass

  • Win combat L1.A (1 Goblin Base) → +5..10g run gold
  • Win combat với Tank/Special variant → +6..12g (×1.2 multiplier)

  • Mỗi win → -3 stress cho 1 random alive hero (verify run state)
  • Verify auto: CombatRewardRollerTest 7 cases pass
